#Actividad 4. Memotest

En esta actividad ya viene (casi) construido un programa para jugar al Memotest. 
Sin embargo, por un descuido, falta una de las funciones: la que verifica si las dos cartas que se destaparon son 
iguales, "`las cartas son iguales`". Completá el programa para que se pueda jugar; el escenario en medio del juego 
debería verse como el siguiente.

<center>
![Un escenario durante el juego](assets/resources/Imagen1-small.png)
</center>

En el juego del Memotest, el usuario selecciona dos cartas que están tapadas (no se vé su valor), y si las cartas son iguales, 
las mismas quedan destapadas y se continúa buscando, pero si no lo son, vuelven a taparse.
El juego continúa hasta que todas las cartas están destapadas (se supone que hay dos iguales de cada carta que aparezca).

> **Mirando las cartas**
>
> Para poder saber el `valor` y el `palo` de una carta, hay funciones primitivas especiales. ¡Buscalas!

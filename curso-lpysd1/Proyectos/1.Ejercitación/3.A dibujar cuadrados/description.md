# Proyecto: A dibujar cuadrados

La idea es que dibujes cuadrados rojos, como se muestra en la figura.
Pero tenés que usar tu propio comando para dibujar un cuadrado, y para eso
tenés que escribir un procedimiento.  

<center>
![Tablero final esperado en la parte 2](assets/resources/Imagen1-small.gbb)
</center>

La parte más complicada es la de mover el cabezal hasta donde hay que empezar a dibujar… 
¡No te olvides de usar procedimientos para expresar las subtareas de movimiento!
Y de ponerles nombres adecuados, por supuesto.

¡Ah! Fijate que para lograr que se vea como en la figura, tenés que activar la vestimenta.
Es lo podés hacer usando el botón con forma de ojo que aparece arriba del escenario.

> **Recordatorio**
>
> Un comando es la descripción de una acción. 
> Puede ser un comando primitivo o uno que haya sido definido mediante un procedimiento. 
> Y puesto que los comandos describen acciones, cuando definimos un comando nuevo, elegimos como 
> nombre algo que empieza con un verbo, al igual que los nombres de los comandos primitivos: dibujar, 
> poner, mover, etcétera.
